# Customer handout - stage rollout time and cost

This one-pager helps customers decide how far to go in a workshop or pilot. Costs are expressed as drivers and formulas rather than unsupported flat ranges. Use the dated [cost guide](COST-GUIDE.md), the [Azure pricing calculator](https://azure.microsoft.com/pricing/calculator/), and the customer's agreement.

## Planning assumptions

- Default regions: North Europe; App Service and its diagnostic Event Hub in West Europe; optional AI, SRE Agent, and Health Model resources in Sweden Central.
- A continuously provisioned month is approximately 730 hours.
- Stage A is required. Stages B-E are progressive. AI, SRE Agent, and Observability Agent are optional and off by default.
- The two Log Analytics 1 GB/day caps are ingestion guardrails, not full-cost caps.
- Price every provisioned resource and every usage meter; do not interpret a missing or zero-price allowance row as permanently free service.

## Stage-by-stage estimate

| Stage | Typical deployment time | Incremental cost model |
|---|---:|---|
| A - Foundation | 8-15 min | Two LAW ingestion/retention paths + storage capacity/operations + Event Hubs Basic (`1 TU x provisioned hours + ingress events`) + Key Vault operations + Azure Monitor workspace metrics. |
| B - Workloads and dashboards | 20-35 min | `1 AKS B2s node x running hours` + `1 Linux B2s VM x hours` + `1 Windows B2s VM x hours` + disks/IPs/load balancer + App Service B1 plan-hours + Managed Grafana Standard node-hours and users + Prometheus samples/queries + network monitoring + standard web-test executions + telemetry. |
| C - Alerts and response | 5-12 min | Metric/log-search/dynamic-threshold rule evaluations and series + notifications + action executions + Logic Apps usage + telemetry generated by tests. |
| D - Security posture | 5-12 min | Scheduled-query alert evaluations + Azure Activity/diagnostic ingestion and retention. |
| E - Optional advanced | 10-20 min | Sentinel analysis + archive/search/restore + data/metrics export + LAW replication + extra retention/telemetry. Trial and preview allowances are conditional, not permanent zero-cost assumptions. |
| AI - Optional GenAI | 5-10 min + traffic | Per-model input, cached-input, output, embedding, routing, and optional PTU rates for `gpt-5-mini`, `text-embedding-3-small`, `gpt-5.4`, and `model-router`, plus App Insights telemetry. |
| SRE Agent - Optional | 5-10 min + portal setup | `always-on AAUs x current rate + active AAUs x current rate`, subject to current trial eligibility. Stopping activity does not stop a post-trial always-on allocation. |
| Observability Agent - Optional | 5-10 min + investigations | `AAC consumed x current regional AAC rate + dedicated workspace data charges`. Correlation is unbilled in the preview terms checked September 27, 2026; chat and deep investigation consume AAC. |
| Control Center runner | Per execution | ACR Basic registry-days/storage + ACR Tasks build vCPU-seconds + Container Apps job vCPU/GiB-seconds (1 vCPU, 2 GiB, up to 1,800 seconds/run) + logs. No always-running app replica is deployed. |

## Customer conversation checklist

1. Select only the stages needed for the workshop.
2. Enter each fixed SKU, count, region, and expected provisioned hours in the pricing calculator.
3. Estimate daily ingested GB separately for both LAWs and add retention, archive, search, restore, export, and replication plans.
4. Add active Grafana users, web-test frequency, alert dimensions/evaluations, flow-log GB, Traffic Analytics GB, Prometheus samples, and runner executions.
5. Add model-specific token assumptions and agent allocations only when those optional stages are enabled.
6. Set a Cost Management budget and review actual cost by service, meter, resource, and tag after the workshop.

## Lifecycle guidance

- Deallocate VMs, scale the VMSS down, and stop AKS outside workshop windows.
- Stopping the web app does not stop App Service Plan billing.
- Disks, public IPs, Grafana Standard, Event Hubs, ACR, retained data, and telemetry can continue billing after compute stops.
- Delete the SRE Agent before an eligible trial ends if the evaluation will not continue.
- Keep Observability Agent automatic investigations disabled unless AAC consumption is explicitly accepted.
- Run `./scripts/teardown.ps1 -Yes` when finished, then verify asynchronous resource-group and separately managed resource deletion completes.
